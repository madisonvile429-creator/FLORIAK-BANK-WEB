# FLORIAK BANK — Website Starter

A responsive front-end recreation inspired by the supplied design reference.

## Included files
- `index.html` — page structure and content
- `style.css` — layout, colors, responsive design and visual styling
- `script.js` — mobile navigation, hide/show balance, demo dialogs
- `assets/hero-reference.jpg` — cropped visual reference from your uploaded image
- `assets/bank-building.jpg` — cropped building photo from your uploaded image

## Run it locally
1. Unzip the downloaded folder.
2. Open `index.html` in a modern browser. For best results, use VS Code with the Live Server extension.
3. To edit the site, open `index.html`, `style.css`, or `script.js`.

## Publish with GitHub Pages
1. Sign in or create an account at https://github.com/.
2. Create a new repository named `floriak-bank-website`.
3. Upload all files and the `assets` folder, keeping the same folder structure.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then press **Save**.
7. Wait for the deployment to finish. GitHub will show the public website URL in Settings → Pages.

## Important security note
This is a visual front-end demo only. The balances and transactions are sample content. Login, account creation, transfers, payments, and customer data are not connected to a backend. Never use this demo to collect real passwords, bank details, PINs, or OTPs. A real financial product needs secure authentication, a compliant backend, encrypted transport, audit logging, fraud controls, and relevant regulatory approvals. Replace the sample image crops with licensed production images if you have original assets.
